Variables & Template Syntax Guide

Personalize outgoing messages dynamically and safely with recipient tags and spintax
Supported Contact Variables
Spintax Word Randomization
Use curly brackets with pipes to randomize wording per contact and protect sender reputation:
{Hello|Hi|Greetings} {first_name}, {hope you have a great day|wishing you the best}!
Each recipient receives one random variation chosen independently.
Default / Fallback Values
Provide fallback values if an optional contact attribute is blank:
Hello {name|there}, your {tier|VIP} member status is active.
